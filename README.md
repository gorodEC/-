# Новости.ру — Mediastack и только русский язык

## Настройка
1. Установите Node.js 20.6+ (нужна поддержка `--env-file`).
2. Получите API-ключ Mediastack через APILayer: https://mediastack.com/
3. В корне проекта скопируйте `.env.example` в `.env`.
4. Откройте `.env` и замените `PASTE_YOUR_MEDIASTACK_KEY_HERE` на свой ключ.
5. В терминале в папке проекта выполните `npm start`.
6. Откройте http://localhost:3000.

Не публикуйте `.env` и не добавляйте секретный ключ в клиентский JavaScript. Сервер хранит ключ, делает запрос к Mediastack и кэширует ответ на 15 минут.

## Что делает интеграция
- Запрашивает Mediastack через `https://api.apilayer.net/mediastack/news`.
- Передаёт `languages=ru` и не ограничивает страну источника: фильтруются именно русскоязычные материалы.
- Повторно проверяет `language === "ru"` и страну `ru` на сервере; клиент тоже проверяет языковую метку и наличие кириллицы.
- Сохраняет фильтры по темам: политика, спорт, экономика и технологии.
- Ошибки API показываются на странице. Автообновление отключено, чтобы не расходовать лимит запросов; ручное обновление использует серверный кэш.

## Важные замечания
Mediastack требует ключ API. Если ключ не настроен, сайт покажет понятную ошибку вместо бесконечной загрузки. Доступность HTTPS и актуальных данных зависит от API-плана; бесплатный тариф может выдавать задержанные новости. Если API не поддерживает конкретный параметр на вашем плане, текст ошибки появится на сайте.
